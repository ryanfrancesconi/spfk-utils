General utilities that need more than Foundation: AppKit, Core Graphics and Core Animation
extensions, timers, batch processing, and persisted table and outline state.

## Features

- AppKit, Core Graphics and Core Animation extensions
- Display-link timers
- Bounded-concurrency batch processing, including batch file conversion
- A sharded disk cache for decoded images (`ImageDataStore`)
- CSV and XML helpers
- Outline nodes, expansion state, table column layout and sort state
